## Working hypothesis (to test, not a conclusion)

Many SOC estimation papers address a single cell or a centralized pack. Many fault papers address cell or pack faults but not what happens to state estimation when a **distributed node drops out or a sensor fails**.

Candidate gap: **SOC estimation and fault management that remain accurate when a distributed node or its sensor fails**, for example by distinguishing sensor failure from a genuine cell fault and reconstructing or bounding the missing data.

Related lead: Highly Available Li-Ion Batteries Sensors Readings Prediction Framework (IEEE Access, 2025) reconstructs faulty readings with an LSTM. Check how far it goes in a distributed, multi-node setting.
